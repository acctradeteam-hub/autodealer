# Разбор аукциона

```bash
python3 -m auction_analysis ~/Downloads/auction_all_2026-11-10_1326.csv
```

На вход — файл логгера `auction_all_<дата>_HHMM.csv`. Результат — `out/auctions/<дата>/report.md`
и `tables.xlsx`. Нужны `pandas`, `openpyxl`, `PyYAML`.

Разделы всегда одни и те же: 0. полнота данных, 1. сводка по аукционам, 2. наше участие,
3. покупатели и андербиддеры, 4. цены по сегментам и моделям, 5. ушедшие дёшево и непроданные.
Настройки (наши имена и бейджи, buy box, пороги) — в `config.yaml`.
