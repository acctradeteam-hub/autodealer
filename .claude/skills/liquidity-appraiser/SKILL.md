# Оценщик ликвидности

Считает, сколько максимум можно дать за лот на аукционе, чтобы после доставки,
подготовки и продажи остался заданный запас прибыли.

## Что делает

1. Берёт цены конкурентов (comps) по модели, отбрасывает выбросы, считает медиану.
2. Корректирует на пробег и состояние лота.
3. Ограничивает цену коридором CarGurus (по умолчанию — порог рейтинга `good`).
4. Вычитает логистику, подготовку, сборы аукциона и расходы на продажу.
5. Вычитает запас: `max(минимальная прибыль в $, процент от цены продажи)`.
6. Подбирает ставку с учётом того, что сбор аукциона сам зависит от ставки.

## Как запускать

```bash
python3 -m appraiser.cli --data-dir <папка с данными> --out-dir out
```

Результат: `out/bids.csv` (сводка по всем лотам) и `out/cards/<lot_id>.md`
(карточка с пошаговым расчётом на каждый лот).

Проверить, что всё работает: `python3 -m appraiser.cli --data-dir data/example --out-dir out`

## Какие файлы нужны в папке данных

| Файл | Обязателен | Назначение |
|---|---|---|
| `lots.csv` | да | лоты: `lot_id, vin, year, make, model, mileage, condition_grade, title_status, auction_location, destination, distance_miles, recon_override_usd, transport_override_usd` |
| `comps.csv` | да | объявления конкурентов: `comp_id, make, model, year, mileage, price, distance_miles, days_on_market` |
| `cargurus_ranges.csv` | нет | коридор CarGurus: `make, model, year_from, year_to, great_deal_max, good_deal_max, fair_deal_max` |
| `model_thresholds.csv` | нет | пороги по модели: `make, model, max_mileage, max_age_years` (поддерживает `*`) |
| `carriers.csv` | нет | перевозчики: `carrier, phone, email, origin, destination, rate_usd` |
| `lanes.csv` | нет | расстояния: `origin, destination, miles` |
| `config.json` | нет | ставки, сборы, проценты запаса (без него берутся плейсхолдеры) |

Шаблоны с готовыми заголовками лежат в `data/templates/`.

## Правила работы

- **Колонки в чужом файле.** Если у пользователя другие названия колонок — не
  переписывай его файл. Добавь соответствие в `column_aliases` в `config.json`.
- **Цифры.** Значения в `config.json` по умолчанию — плейсхолдеры. Если пользователь
  ещё не дал свои ставки, скажи это прямо в ответе и не выдавай результат за готовый
  к торгам.
- **Данные текстом.** Если пользователь прислал цены конкурентов сообщением, а не
  файлом — разложи их в `comps.csv` в папке данных и запусти расчёт заново, чтобы
  цифры считал код, а не модель в уме.
- **Никаких живых источников.** Оценщик не ходит в CarGurus, Copart и Central Dispatch.
  Данные поступают только из файлов. Не утверждай, что цены «актуальные» — они такие,
  какими их подали. Адаптер `appraiser/sources/cargurus_dealer.py` — заглушка, он
  намеренно не реализован.
- **Стоп-правила важнее ставки.** Лот с титулом не из списка разрешённых, с пробегом
  или возрастом выше порога модели получает `ОТКАЗ` без расчёта. При нехватке
  конкурентов (по умолчанию меньше трёх) ставка не считается — `РУЧНАЯ ПРОВЕРКА`.
- **Всегда показывай, сколько конкурентов найдено и сколько взято** — это уже есть в
  карточке и в CSV (`comps_found`, `comps_used`).
