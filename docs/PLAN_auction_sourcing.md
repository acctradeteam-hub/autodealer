# План: «одно окно» для подбора машин на аукционах и расчёта максимальной ставки

Статус: проект для обсуждения, 29.09.2026. Код по этому плану ещё не написан.

## Что должно получиться

Вводим марку/модель (плюс, по желанию, годы, пробег, радиус) → получаем таблицу
лотов со всех подключённых аукционов, которые выставляются в ближайшие дни, и по
каждому лоту:

| Колонка | Откуда |
|---|---|
| Аукцион, дата/время торгов, локация, VIN, пробег, повреждения, CR-грейд | лента аукциона |
| KBB (для нашего ZIP) | KBB B2B / ICO или ручной ввод |
| Adjusted MMR | Manheim API |
| Ритейл у конкурентов: сколько таких же машин в радиусе, медианная цена, дни на стоянке | MarketCheck (дилерский инвентарь) |
| Carfax: ДТП, владельцы, аренда/флит, брендированный титул, сервис | Carfax for Dealers |
| **Макс. ставка (hammer), $** и ожидаемая прибыль | наш расчёт |
| Вердикт: брать / торговаться до X / пропустить + причина | наш расчёт |

## Главный вывод из поиска: готовые решения уже есть

- **vAuto Stockwave** (Cox Automotive) — ровно эта задача: поиск по 300+ оптовым
  площадкам (~300 тыс. машин в день), рыночные данные по каждой машине и
  «бизнес-планы» с порогом прибыли, чтобы показывать только выгодные лоты.
- **MarketCheck API** — поиск по аукционным лотам (~500 тыс. в день),
  инвентарь любых дилеров за 90 дней (= конкуренты), история VIN за 6 лет,
  прогноз цены, market days supply. Это лучший «конструктор» для своей системы.
- **Manheim Developer API** — MMR и листинги Manheim, доступ через представителя Cox.
- **Калькуляторы ставки** (AuctionCalc, BidMax, AuctionIQ) — считают только
  формулу, без поиска; для Copart/IAA и битых машин.

Поэтому есть два пути:

| Путь | Плюсы | Минусы |
|---|---|---|
| **Купить** Stockwave (+ Carfax for Dealers) | Работает сразу, данные легальные и свежие | Подписка; формула и расходы — в их рамках; нет Copart/IAA (salvage) |
| **Собрать своё** на MarketCheck + Manheim API + Carfax | Своя формула, свои расходы, свои аукционы, свой интерфейс | Платные API и договоры, 4–8 недель разработки |

Разумная середина: попробовать Stockwave (демо), а своё строить только если
его формула/охват не подходят.

## Чего делать не стоит

Парсить сайты Manheim/ACV/Copart/KBB/Carfax роботом под своим логином:
нарушение условий использования, блокировка аккаунтов покупателя, ломается
при каждой правке сайта. Для KBB нет открытого API — только B2B-договор,
либо ручной ввод / сохранённые страницы (уже умеет `lot_analyzer`).

## Формула максимальной ставки

```
Цена продажи (R)      = медиана ритейла конкурентов в радиусе, скорректированная
                        на пробег/комплектацию; контроль — KBB и MMR
Скидка за историю (H) = % от R: ДТП, >2 владельцев, аренда/флит, и т.п.
                        Брендированный титул / структурка / откат пробега → «пропустить»
Ремонт (Rec)          = по CR-грейду и повреждениям + резерв (шины, тормоза, стекло)
Детейлинг (D)         = фиксированная сумма
Транспорт (T)         = по расстоянию от площадки до нас
Сборы аукциона (F)    = buyer fee по ступенчатой таблице площадки
                        + internet/proxy fee + gate + title + PSI/гарантия
Содержание (Hold)     = дни продажи × (процент floor plan + стоянка);
                        дни продажи — из days supply конкурентов
Продажа (S)           = реклама, пак, доки
Прибыль (P)           = цель, $ или %; больше при высоком days supply

Макс. «всё включено»  = R − H − Rec − D − T − Hold − S − P
Макс. ставка (hammer) = наибольшая ставка B, при которой B + F(B) ≤ Макс. «всё включено»
                        (F зависит от B ступенями, поэтому решается перебором)
```

Все суммы и проценты — в одном файле настроек, у каждой площадки своя таблица
сборов.

## Реализация (если строим своё)

Форма: небольшое **веб-приложение** (открывается в браузере, работает на вашем
компьютере или сервере). Облачная сессия Claude для этого не подходит: сайты
аукционов и KBB отсюда недоступны (проверено ранее, см. README).

1. **Этап 1 — калькулятор (1 неделя).** Модуль расчёта ставки + файл настроек
   сборов и расходов. Работает на данных, которые уже собирает `lot_analyzer`
   и ручных оценках. Сразу даёт колонку «Макс. ставка».
2. **Этап 2 — данные (2–4 недели, после получения ключей).** Подключение
   MarketCheck (лоты аукционов + конкуренты + история VIN), Manheim API (MMR),
   Carfax (по договору дилера), KBB (B2B или ручной ввод).
3. **Этап 3 — одно окно (1–2 недели).** Поиск по марке/модели, таблица с
   вердиктами, сохранённые поиски и уведомления «появилась выгодная машина».
4. **Этап 4 — обучение на своих сделках.** Сравнение прогноза с фактической
   ценой продажи и затратами, подстройка скидок и резервов.
