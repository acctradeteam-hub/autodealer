# Папка для сохранённых страниц лотов

Положите сюда страницы лотов и запустите разбор:

```bash
python3 -m lot_analyzer samples/
```

## Как сохранить страницу лота

1. Откройте страницу лота и **дождитесь полной загрузки** — на экране должны
   быть видны VIN, пробег, повреждения. Данные подгружаются скриптами, до
   загрузки в файл они не попадут.
2. **Ctrl + S** (на Mac **Cmd + S**).
3. Тип файла — **«Веб-страница, полностью» / «Webpage, Complete»**.
   Вариант «Веб-страница, один файл» (`.mhtml`) тоже поддерживается.
4. Сохраните в эту папку. Папка с картинками рядом с файлом не нужна.

Если часть полей не нашлась, есть более надёжный способ снять готовую разметку:
**F12 → вкладка Elements → правый клик по строке `<html>` → Copy → Copy outerHTML**,
вставить в Блокнот и сохранить как `lot.html` в кодировке UTF-8.

## Что учесть

- Поддерживаются `.html`, `.htm`, `.xhtml`, `.mhtml`, `.mht`.
- Один файл = один лот. Страницы со списком лотов пока не разбираются
  (настраивалось под карточку одного лота).
- Файлы из этой папки **не попадают в git** (см. `.gitignore`): в сохранённой
  странице обычно есть данные вашего аккаунта аукциона.
