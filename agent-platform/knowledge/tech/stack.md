# Технологический стек проектов

- Агенты: Python, Claude API через внутренний LLM Gateway, оркестрация кодом.
- Хранилище знаний: Postgres + pgvector, полнотекстовый поиск для коротких справочников.
- Развёртывание: Docker, для клиентов с закрытым контуром — on-premise установка.
- Наблюдаемость: журнал запусков, трассировка шагов, оценка качества на наборе эталонных примеров.
