# Чек-лист интеграции с учётными системами

1. Сервисная учётная запись с минимальными правами, отдельная для каждого агента.
2. Запись в систему клиента — только через очередь с подтверждением человеком на пилоте.
3. Журнал всех действий агента хранится у клиента не меньше года.
4. Для 1С — REST-сервис или OData; для amoCRM и Битрикс24 — официальный API.
