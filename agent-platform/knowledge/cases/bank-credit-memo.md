# Агент подготовки кредитных заключений для банка (NDA)

**Задача.** Подготовка кредитного заключения по малому бизнесу занимала у аналитика 2 дня.

**Решение.** Агент собирает данные из внутренних систем банка и пишет черновик заключения по шаблону кредитного комитета.

**Результат.** Пропускная способность отдела выросла в 3 раза. Кейс под NDA: название банка и цифры нельзя использовать в продажах.
