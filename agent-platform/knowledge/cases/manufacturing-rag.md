# База знаний по технической документации для машиностроительного завода

**Задача.** 12 000 документов (регламенты, чертежи, инструкции), инженеры тратили до 15 минут на поиск ответа.

**Решение.** Поиск с ответами по документам (RAG) со ссылками на источник, обучение 4 групп инженеров.

**Результат.** Время поиска ответа сократилось с 15 минут до 40 секунд, 85% инженеров пользуются системой еженедельно.
