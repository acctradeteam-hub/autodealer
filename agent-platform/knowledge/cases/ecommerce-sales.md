# AI-консультант для интернет-магазина

**Задача.** Покупатели уходили с сайта, не получив ответа о совместимости и наличии товаров.

**Решение.** Агент-консультант на сайте с доступом к каталогу и остаткам, сопровождение по SLA.

**Результат.** Конверсия посетителей, общавшихся с агентом, выше на 18%, средний чек вырос на 9%.
