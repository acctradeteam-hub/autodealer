# Ручные оценки

`manual_values.tsv` создаётся автоматически при первом запуске: в него
добавляется строка на каждый новый VIN. Заполняйте колонки руками — разбор
страниц их не затирает.

| Колонка | Что вписывать |
|---|---|
| `KBB Private Party, $` | Private Party Value с kbb.com для этого VIN, пробега и штата |
| `Adjusted MMR, $` | Adjusted MMR из Manheim (если не нашёлся на сохранённой странице) |
| `Ритейл CarGurus, $` | Цена, при которой CarGurus даёт нужный рейтинг |
| `Рейтинг CarGurus` | Great Deal / Good Deal / Fair Deal |
| `Максимальная ставка, $` | Ваш потолок по лоту |
| `Carfax / AutoCheck` | Краткие выводы из отчёта |
| `Condition Report` | Краткие выводы из CR (Manheim / ACV) |

Правило перезаписи: значение из этого файла **перекрывает** найденное на
странице. Оставьте клетку пустой, чтобы сохранить то, что нашёл парсер.

Файл открывается в Excel (это TSV, разделитель — табуляция, кодировка UTF-8).
