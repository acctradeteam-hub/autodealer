# Оценщик ликвидности

Расчёт рекомендуемой максимальной ставки на автоаукционе: сколько максимум можно
дать за лот, чтобы после доставки, подготовки и продажи остался заданный запас.

Работает на файлах (CSV/Excel), без обращений в интернет. Python 3.11+, только
стандартная библиотека (openpyxl нужен, только если входные файлы в `.xlsx`).

## Быстрый старт

```bash
git clone <репозиторий> && cd autodealer
python3 -m appraiser.cli --data-dir data/example --out-dir out
```

На экране появится сводка, а в `out/` — `bids.csv` и карточки лотов.
Готовый результат тестового прогона лежит в `examples/output/`.

## Работа со своими данными

1. Скопируйте шаблоны: `cp -r data/templates data/private` (папка `data/private`
   не попадает в git).
2. Заполните `lots.csv` и `comps.csv`; при наличии — `cargurus_ranges.csv`,
   `model_thresholds.csv`, `carriers.csv`, `lanes.csv`.
3. **Впишите свои цифры в `data/private/config.json`**: сборы аукциона, тариф за милю,
   стоимость подготовки, минимальную прибыль и процент. Значения из коробки —
   плейсхолдеры, а не ставки вашего дилершипа.
4. Запустите: `python3 -m appraiser.cli --data-dir data/private --out-dir out`

Если у вашей таблицы другие названия колонок — не переименовывайте их вручную,
добавьте соответствие в `column_aliases` в `config.json`:

```json
"column_aliases": { "lots": { "Odometer": "mileage", "Lot #": "lot_id" } }
```

## Формула

```
цена быстрой продажи = медиана конкурентов
                       + поправка на пробег
                       + поправка на состояние
                       ограничена коридором CarGurus
                       − скидка на быструю продажу

запас = max(минимальная прибыль в $, процент от цены продажи)

максимальная ставка: наибольшая ставка, при которой
ставка + сбор аукциона(ставка) + логистика + подготовка
      + фикс. сборы + расходы на продажу + запас ≤ цена быстрой продажи
```

Сбор аукциона зависит от самой ставки (ступенчатая шкала), поэтому ставка
подбирается делением отрезка пополам и округляется вниз до шага торгов.

## Стоп-правила

| Условие | Решение |
|---|---|
| титул не из `rules.allowed_titles` (по умолчанию только `clean`) | `ОТКАЗ`, расчёт не выполняется |
| пробег или возраст выше порога модели из `model_thresholds.csv` | `ОТКАЗ` |
| конкурентов меньше `market.min_comps_required` | `РУЧНАЯ ПРОВЕРКА` |
| не удалось определить стоимость доставки | `РУЧНАЯ ПРОВЕРКА` |
| ставка ≤ 0 или ниже `rules.min_bid_floor_usd` | `ПРОПУСТИТЬ` |

В карточке и в CSV всегда видно, **сколько объявлений найдено и сколько взято**
в расчёт (`comps_found` / `comps_used`), а также плотность предложения по модели
(`supply_label`: HIGH / MEDIUM / LOW) и диапазон цен конкурентов.

## Откуда берутся рыночные данные

Только из файлов, которые вы готовите. Оценщик **не** ходит сам в CarGurus, Copart,
Manheim или Central Dispatch:

- публичного API для выгрузки объявлений у CarGurus нет;
- автоматический обход сайта нарушает условия использования и ломается при смене вёрстки;
- в веб-сессии Claude Code внешняя сеть закрыта политикой окружения (проверено: домены
  рыночных данных отдают 403 на уровне прокси).

`appraiser/sources/cargurus_dealer.py` — слот адаптера на будущее. Он намеренно не
реализован и сообщает, чего не хватает, вместо тихой выдачи пустых данных. Чтобы он
заработал, нужен легальный источник (выгрузка из дилерского кабинета файлом или
лицензированный API с ключом) и локальный запуск с открытой сетью.

## Структура

```
appraiser/          расчётное ядро
  market.py         цена быстрой продажи по конкурентам и коридору CarGurus
  costs.py          сборы аукциона, доставка, подготовка, расходы на продажу
  bid.py            запас и подбор максимальной ставки
  rules.py          стоп-правила
  pipeline.py       сборка расчёта по лоту
  report.py         bids.csv и карточки
  sources/          провайдеры рыночных данных
data/example/       тестовый набор (данные выдуманные)
data/templates/     пустые шаблоны с заголовками
examples/output/    результат тестового прогона
tests/              26 проверок
.claude/skills/liquidity-appraiser/   навык для Claude Code
```
